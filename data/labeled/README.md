# Overview of labeled datasets

This folder contains labeled text datasets used throughout the project. The table below summarizes each subfolder by the source paper in Author (Year) format and the task type(s) covered.

Task labels use the following taxonomy:

- `sentence classification`
- `multi-label classification`
- `span extraction`
- `pairwise comparison`

When a dataset spans more than one task type, multiple labels are listed in a comma-separated list.
